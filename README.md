# SENAI Frameworks Front-end

Este repositório registra as aulas, o conteúdo e o progresso do curso de frameworks front-end do SENAI.

## Objetivo

O objetivo deste repositório é servir como um índice e histórico das aulas de frameworks front-end, documentando o que foi aprendido e apontando para os trabalhos realizados em repositórios separados.



## Atividades realizadas

- [Atividade 1 - React](https://github.com/SEU_USUARIO/atividade-react)
- [Atividade 2 - Angular](https://github.com/SEU_USUARIO/atividade-angular)
- [Atividade 3 - Vue](https://github.com/SEU_USUARIO/atividade-vue)

> Substitua os links acima pelos URLs reais dos repositórios das suas atividades.

## Como usar

Cada atividade foi desenvolvida em um repositório distinto. Use os links da seção anterior para acessar os exercícios e projetos de cada aula. Este repositório principal serve apenas para centralizar o registro das aulas e indicar as entregas existentes.
