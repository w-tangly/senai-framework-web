# SENAI Frameworks Front-end

Este repositório registra as aulas, o conteúdo e o progresso do curso de frameworks front-end do SENAI

## Como usar

Cada atividade foi desenvolvida em um repositório distinto. Use os links da seção anterior para acessar os exercícios e projetos de cada aula. Os arquivos e pastas presentes dentro deste repositório serão usados para realizar o armazenamento e gerenciamento de conteúdo das aulas. Este repositório principal serve apenas para centralizar o registro das aulas e indicar as entregas existentes.

## Objetivo

O objetivo deste repositório é servir como um índice e histórico das aulas de frameworks front-end, documentando o que foi aprendido e apontando para os trabalhos realizados em repositórios separados..

## Plano de ensino da matéria

Ao final da unidade curricular, o estudante deve ser capaz de programar aplicações responsivas para a internet, voltadas ao uso em ambientes industriais de produção, abordando Tecnologias Front-end, Framework para CSS e Framework para Front-End.

### Objetivo
Programar aplicações responsivas para a internet, tendo em vista a utilização em ambientes industriais de produção.

### Capacidades técnicas
- Configurar o ambiente de desenvolvimento para aplicações Web.
- Aplicar tecnologias front-end na programação da interface do usuário.
- Elaborar códigos WEB respeitando boas práticas e convenções de código.
- Definir os frameworks de programação conforme a necessidade da linguagem.
- Criar aplicações web de acordo com UX e práticas responsivas.

### Capacidades socioemocionais
Ética, pensamento crítico e inovação, e resolução de problemas complexos.

### Conteúdos e conhecimentos
1. Tecnologias Front-end (Responsividade, Ferramentas do desenvolvedor, Framework)
2. Framework para CSS (Definição, Instalação, Utilização)
3. Framework para Front-End (Definição, Configuração, Pacote NPM, Rotas, Componentes/propriedades/estados)
