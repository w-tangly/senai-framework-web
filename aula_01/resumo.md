## 📌 1. Visão Geral e Contexto da Disciplina
O objetivo desta disciplina é capacitar o aluno a desenvolver aplicações web modernas utilizando Frameworks Front-end.

* *Por que isso importa?* No mercado atual, as empresas necessitam de interfaces rápidas, organizadas, fáceis de manter e que proporcionem excelente experiência ao usuário, sendo um requisito estratégico para a competitividade empresarial.

* *O que é o Front-end?* É a camada da aplicação com a qual o usuário interage diretamente (responsável pelo visual, organização dos elementos, experiência do usuário/UX e comunicação com os sistemas de backend).

## 📚 2. Conteúdo Programático do Semestre
A jornada de aprendizado abrangerá os seguintes pilares:

1. *Fundamentos e Ferramentas*: Configuração do ambiente de desenvolvimento, controle de versão com *Git e GitHub*, e publicação (deploy) de aplicações na web (ex: Vercel).

2. *JavaScript Puro (Vanilla JS)*: Revisão e aprofundamento em JavaScript sem dependências externas, servindo de base para as abstrações seguintes.

3. *Frameworks Front-end*: Conceitos de arquitetura, componentização (reutilização de código), gerenciamento de estado, rotas e integração com APIs. Serão introduzidas ferramentas de mercado como *React, Vue e Angular*.

4. *Boas Práticas*: Padrões de projeto, organização de código e criação de portfólio profissional.

## 🛠️ 3. Metodologia de Ensino
* Aulas expositivas e dialogadas para construção conceitual.

* Discussões em sala para estimular o pensamento crítico.

* Estudos de caso e cenários industriais reais, conectando a teoria à prática profissional.

## 📝 4. Critérios de Avaliação
A nota final é distribuída da seguinte forma:

* 55% - Avaliação Docente:

    * 20% - Desenvolvimento de Projeto (documentação completa estilo "mini TCC", cobrindo planejamento, execução e desafios).

    * 20% - Apresentação do Projeto (focada em gestão de backlog, páginas desenvolvidas e análise de benchmarking).
    
    * 15% - Realização das atividades semanais.

* 35% - Projeto Integrador.

* 10% - Autoavaliação.

> 💡 Dica Importante: Criar um portfólio de projetos ao longo da disciplina demonstra habilidades práticas, atrai oportunidades de estágio/emprego e serve como evidência concreta do seu aprendizado.

## 🎯 5. Atividades Práticas Iniciais
* Atividade 01: Criar um projeto utilizando Vanilla JS (HTML, CSS e JavaScript), conectar a IDE ao GitHub e realizar o deploy da aplicação utilizando a ferramenta Vercel.

* Atividade 02:

    1. Formar grupos de 3 a 5 integrantes (que serão mantidos durante as entregas do semestre).

    2. Criar um repositório no GitHub para centralizar as atividades e adicionar um arquivo Markdown com o resumo desta aula.

    3. Escolher um Framework Front-end em grupo e elaborar um relatório técnico em PDF (mínimo de 5 páginas) abordando suas características, vantagens, mercado e um exemplo prático de uso.
